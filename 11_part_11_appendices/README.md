# Part 11：附錄 導讀

> 第一次閱讀本 Part 時，建議先讀完本導讀，再進入各章節。

## 這一 Part 在做什麼

提供術語、工具、Log Package、Bring-up Gate、Release Gate 與文件範本。

## 為什麼需要這一 Part

附錄讓團隊以一致欄位與證據工作，不重複技術章節的原理與測試案例。

## 讀完應能回答

- 工具與縮寫如何統一？
- Log Package 必須包含什麼？
- A04 如何管理 Bring-up Gate？
- A05 如何管理 Release 與 Hotfix？

## 建議閱讀順序

A01 至 A03 日常速查，A04、A05 用於 Gate，A06 用於建立新文件。

## 與其他 Part 的關係

本 Part 不獨立存在。遇到跨領域問題時，應回到 Part 1 判斷韌體階段，再依硬體初始化、OS 介面、安全、更新或測試等相鄰 Part 交叉查閱。
